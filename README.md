# Todo App

Este es un proyecto de lista de tareas desarrollado con JavaScript y Vite. La aplicación permite agregar, marcar como completadas y eliminar tareas de manera sencilla, proporcionando una experiencia rápida y eficiente gracias al entorno de desarrollo optimizado de Vite.

## 🌐 Acceso al proyecto  
Puedes probar la aplicación en el siguiente enlace:  
🔗 [Todo App](https://cmejiajulian.github.io/TodoApp/)

## 🛠 Tecnologías utilizadas  
- JavaScript  
- Vite  
- HTML y CSS
